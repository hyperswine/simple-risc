# A 128-entry BTB

Kind: core change, simulation and timing builds, 2026-10-30. Follows
[BTB-64](2026-10-30-BTB-64.md). No board run.

## Result

128 entries cut cycles by **1.036x** over 64 (IPC 0.342 to 0.355). Against
the core before this session's predictor work the total is **1.306x**. The
classifier output is correct (train 124/128 digest 21562, test 61/64 digest
909572), and the Verilator RTL check passes.

It passes 60 MHz at all three placements, but with less margin: placement 2
has 0.072 ns of slack.

| Design | 60 MHz builds (placements 0 / 2 / 3) | Worst Fmax | IPC | Fmax x IPC |
|---|---|---:|---:|---:|
| Before the predictor work | pass 75.2 / 71.6 / 61.4 | 61.4 | 0.272 | 16.7 |
| 64-entry BTB (8bef546) | pass 64.2 / 63.0 / 61.6 | 61.6 | 0.342 | 21.1 |
| 128-entry BTB | pass 62.9 / 60.3 / 64.3 | 60.3 | 0.355 | 21.4 |

The gain in speed is 1.6% while the worst-case margin falls from 0.43 ns to
0.07 ns.

## What changed

Index pc bits 8..2, tag bits 16..9; 128 valid flip-flops. The table is 128 x
41 and still occupies the same two block RAMs (40 of 46 in use).

| Version | Cycles | E2 redirects | Front redirects | Logic | Registers |
|---|---:|---:|---:|---:|---:|
| 64 entries | 115,446,617 | 1,496,193 | 1,932,168 | 15,259 | 5,206 |
| 128 entries | 111,417,922 | 1,117,098 | 1,537,453 | 14,907 | 5,271 |

Taken branches without a prediction fell from 1.19M to 0.80M; not-taken
mispredictions rose slightly (302K to 314K). Logic fell by 352 LUTs, which is
synthesis variation rather than a saving the change explains.

## Timing

The worst paths at placements 0 and 2 are the BTB loop: the pending write's
index through the bypass compare, the 128-way valid select and the hit
decision to the next fetch pc, which is the block RAM's read address (12
logic levels, 71% routing at placement 2).

## Open

- The margin is thin. Shortening the BTB loop (for example, dropping the
  pending-write bypass into a separate stage, or reading valid bits from the
  RAM with a reset sweep) would make 128 entries as safe as 64.
- Not run on the board; no gate-level simulation.
