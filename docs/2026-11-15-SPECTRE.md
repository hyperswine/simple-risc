# Spectre system

Spectre names the system around the Simple-Risc processor. Its intended Tang Nano
20K configuration combines the core, 8 MiB SDRAM, a UART boot/recovery console,
SD card storage, an Ethernet adapter for wired networking and an SX1262 radio.
QOS Native is the OS being ported to this system. The name does not rename the
CPU or imply that every FPGA preset or board has all these peripherals attached.
Adapter model, wiring, bus allocation and OS drivers remain to be specified.

## First physical timer probe (15 November 2026)

The ROM on the connected Tang Nano reported the following identity:

    SRID1 isa=rv32imc cpu=00000036 mem=00000036 ram=00800000 max=00200000 cap=PMXQVHTUICG id=9819062505a27795

The installed CPU and memory clocks were both 54 MHz. The 416-byte QOS
hal/spectre/timer.S probe image (SHA-256
f9913e29118fd048af9f6fe95a1d17affb1e7d96b29e443353a84cd92444ea60)
ran via run_program.py --protocol u --freq-mhz 54 --timeout 2 from SDRAM.
Observed UART output:

    spectre timer-v1: two timer returns OK

Foreground code emits this only after two timer interrupts have returned. The
probe parks afterward; the generic uploader expects DONE and timed out, sending
Ctrl-C. This qualifies the timer path on this build, not fprisc-84, cold boot,
QOS scheduling, storage or either network peripheral. No bitstream was flashed.
